# 회사 API 응답 지연 시 로컬 기능 사용

로컬 프런트의 http://localhost:15173/local-tools 에서 기상·통신 시험 컴포넌트를 독립 실행한다. 사건 목록·장비·지도 조회가 완료되어야 로컬 기능에 접근할 수 있던 의존성을 우회하는 별도 진입점이다. 통합상황판의 재난·장비 자료를 대체하거나 모사 데이터를 만들지 않는다.

라우트는 localhost/127.0.0.1에서만 선택된다. 기상 위치는 사용자가 현재 위치를 요청하거나 직접 입력한다. 사건 좌표가 없으므로 사건 위치 버튼은 비활성이다. 기상은 기존 VITE_WEATHER_API_BASE_URL, 통신 시험은 127.0.0.1:18892와 Bearer 토큰을 계속 사용한다. 통신 서버·기상 서버를 켜 둬야 하며 장비 미설정 상태는 미시험이다.

이 페이지는 회사 사건·장비 API를 조회하지 않지만, 사용자가 기상 조회를 요청하면 설정된 날씨 서버를 통해 기상청을 조회한다. 통합상황판 연결 복구, 인증키 권한, RF 장비 드라이버나 실물 출력 문제를 해결한 것으로 간주하지 않는다. 루트(/)와 /device의 기존 기능은 유지한다.

진단 시 15173(프런트),18891(기상),18892(시험) 포트 상태와 회사 API 상태를 구분한다. 회사 API health 성공만으로 실제 재난/장비 조회·CORS가 정상이라고 단정하지 않는다. 요청 제한 시간과 응답 지연이 비슷하면 네트워크·서비스 지연을 추가 확인한다. 운영 서버·회사 배포는 변경하지 않는다.
