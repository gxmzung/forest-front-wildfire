# 상단 운영 현황 잘림 수정

상단 투입 장비·인원·통신망·경보 버튼은 이전 46px 고정 폭 안에서 이름과 숫자를 가로 배치해 서로 밀어냈다. 작은 글씨로 줄이거나 overflow:hidden으로 숨기는 대신 이름 위/숫자 아래 배치와 내용에 필요한 최소 폭을 사용한다. 숫자가 커지면 내용 폭을 확보하고 부족한 화면에서는 전체 묶음이 다음 줄로 내려간다.

기본 운영 헤더는 flex-wrap과 자동 높이를 사용한다. 자산 등록·관리 버튼도 고정 폭과 절대 위치를 해제하고 같은 흐름 안에 둔다. 좁은 화면(900px 이하)에서는 네 개 현황을 전체 폭 한 줄에 균등 배치하며, 각 항목의 문자 줄바꿈을 허용한다. 사건 선택과 기존 도구 메뉴·카운터 버튼 동작은 변경하지 않는다. 전시 모드 hybrid-exhibition-mode는 별도 헤더 디자인을 유지한다.

기존 테마 뒤에 header-readability.css를 불러와 해당 운영 헤더만 보완한다. 상단 전체를 잘라내거나 정보를 숨겨 해결하지 않는다. 실제 브라우저 렌더링과 여러 해상도의 최종 확인은 필요하다. 회사 운영 사이트에 직접 배포하지 않고 개인 저장소에만 반영한다.
