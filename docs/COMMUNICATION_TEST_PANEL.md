# 로컬 통신 시험 표시

## 화면 표시 우선순위

기본 화면에는 통신 종류별 시험 결과, 선택한 시험과 경광봉 요청/출력 상태를 표시한다. 실행 가능한 드라이버가 있는 경로에만 시험 버튼을 표시한다. 토큰·연결 버튼·LED 출력 설명은 닫힌 '시험 연결·출력 설정'에 둔다. 장비별 수신 데이터와 Sleno/NET-01/NMS/BMS/SEQ/Gateway 상세는 각각 접힌 영역에서 확인한다. 숨김은 화면 정리이며 데이터 조회와 판정 기준은 바꾸지 않는다.

현장 기상은 지원되는 다섯 항목(기온·습도·풍속·풍향·1시간 강수량)과 관측 시각을 기본 표시한다. API 미제공 최대순간풍속 카드는 숨기고 출처·제공 항목에 이유를 남긴다. 좌표 입력은 접고 현재/사건 위치 조회는 유지한다. 예보와 전국 특보는 접힌 제목에서도 수신 실패·확인 불가를 구분하며, 실패를 '특보 없음'으로 표시하지 않는다. API 수신 문제 자체를 해결한 변경은 아니다.

통신 탭 상단에서 LTE·5G·이음5G·Wi-Fi·Bluetooth·LoRa·TVWS·LPWA를 독립 표시한다. 노트북 어댑터 Up이나 관제 API 성공을 무선 실증 성공으로 사용하지 않는다.

연결 대상은 노트북 전용 `http://127.0.0.1:18892`이며 forest-integrated-hardware-e2e의 `npm.cmd run start:communication`으로 실행한다. 24자 이상 FOREST_TEST_TOKEN을 서버에 설정하고 화면에서 같은 토큰으로 연결한다. 토큰은 React 메모리에만 유지하며 Git·브라우저 저장소에 보관하지 않는다. localhost 또는 127.0.0.1 상황판에서만 연결 기능을 제공한다. 운영 배포 사이트에는 장치 시험 제어를 열지 않는다.

기본값은 모든 통신 미시험·장치 설정 대기다. 검증된 장비 드라이버가 commissioned=true인 경로만 시험 버튼을 활성화한다. 드라이버 미설정·프로그램 오류는 통신 실패와 다르다. 서버 연결을 잃으면 이전 성공값을 현재 결과로 유지하지 않는다.

한 경광봉은 선택한 단일 시험을 나타낸다. 성공=초록 요청, 실패=빨강 요청이며 미시험·시험 중·오류·만료는 소등 요청이다. 화면의 요청 색과 실제 장치 적용 응답 상태를 분리한다. 드라이버 적용 응답도 실제 광학 피드백 검증과 같지 않다. 화면 연결 해제는 실행 중인 시험 취소가 아니다.

LED는 실물에서만 한 줄·우측 이동으로 출력한다. 상황판에는 LED 모양이나 흐르는 문구를 넣지 않는다. 실제 JK-UR-4 채널 및 전광판 제어기 드라이버·실물 검증은 별도 진행한다. 상세 계약은 통합 저장소 docs/COMMUNICATION_TEST_OUTPUT.md를 따른다.
