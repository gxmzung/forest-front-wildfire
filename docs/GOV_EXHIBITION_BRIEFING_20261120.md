# 정부박람회 대시보드 설명 준비
작성 기준: 2026-11-20. 회사 최신 소스, 전달받은 화면, 로컬 자동 검증 결과를 기준으로 작성했다. 배포 사이트의 실제 장비 수신·제어를 전부 검증한 문서는 아니다.

## 장관님께 전달할 핵심
현장 장비와 지휘부가 같은 지도를 보면서 위치, 영상, 통신 상태를 함께 확인하도록 만든 통합상황판이다. 화면이 있다는 사실보다 현장에서 정보가 실제로 들어오는지, 언제 끊겼는지 확인하는 것이 핵심이다.

## 90초 설명 대본
장관님, 이 화면은 산림재난 현장에서 들어오는 장비 위치와 영상, 통신 상태를 한곳에서 확인하는 통합상황판입니다.

먼저 지도에서 현장에 등록된 대원과 드론, 통신 장비의 위치를 확인합니다. 장비를 선택하면 마지막으로 정보가 들어온 시각과 연결 상태를 볼 수 있습니다. 지도에 보이는 위치가 현재 위치인지, 이전에 받은 위치인지 구분하는 데 목적이 있습니다.

영상은 현장에 연결된 카메라 화면을 함께 확인하는 기능입니다. 통신망 메뉴에서는 수신된 통신 품질과 연결 관계를 확인하고, 문제가 생긴 구간을 살펴볼 수 있습니다.

기상 메뉴에서는 현장 위치의 기온과 바람 등 대응에 참고할 정보를 보여줍니다. 현재 버전은 기상모델 정보를 사용합니다.

이렇게 현장 정보를 한 화면에 모아 지휘부가 상황을 파악하고 대응을 판단하는 데 도움을 주는 것이 목표입니다.

진행 중인 실증의 상태와 범위는 당일 실제 연결 결과를 기준으로 덧붙인다. 실시간 수신이 없으면 실시간 연동 중이라고 설명하지 않는다.

| 현장 경보 | 경보 내용과 현장 전달·확인 상태를 확인합니다. | 경보 조회, FieldLink 전달·확인 추적 코드가 있다. 전달 요청과 현장 수신 확인을 구분한다. |
| 상황 보고 | 현장 자원과 최신 상황보고를 함께 확인합니다. | 등록된 보고를 조회하는 화면이다. 이 메뉴에서 보고 송신·영상 재생은 별도 연계 대기로 표시한다. |
| 현장 KPI | 실증에서 수집한 결과를 수치와 기록으로 확인합니다. | 측정 세션·표본·근거 상태를 구분한다. 목표 수치나 참고값을 달성 실적으로 설명하지 않는다. |
| 연계 상태 | 외부 정보와 서버 연결 상태를 확인합니다. | 공공정보·API 연계 상태를 표시한다. API 정상과 현장 장비 정상은 별개다. |
| FieldLink | 현장과 지휘부 사이 메시지·경보를 연결하는 기능입니다. | 메시지·경보·상태 API와 화면이 있다. 서버 및 현장 단말의 실제 송수신은 별도 확인한다. |
| Semantic AI | 통신이 불안정할 때 필요한 정보를 전달하는 연구 기능입니다. | 현재 Semantic fallback은 PoC이며 운영 패킷은 null이다. 운영 중 AI 판단 기능으로 소개하지 않는다. |
| 대원·장비 / 통신 지휘차 / AI·디지털트윈 / 현장 대응 | 현장 지원 기능과 연결할 정보를 정리한 메뉴입니다. | 보호장비 지급, 차량 계측·방송 제어, 지휘명령 등 여러 항목이 연동 대기 안내다. 메뉴 이름을 구현 완료 실적으로 쓰지 않는다. |

## 시연 순서
1. 지도와 현장 상태를 먼저 보여준다.
2. 당일 실제 수신 중인 장비 하나를 선택한다. 장비 이름, 위치, 최종 수신 시각을 설명한다.
3. 실제 재생되는 영상 한 개를 보여준다. 미연결이면 기능 설명만 하고 넘긴다.
4. 통신망에서 그 장비의 수신된 품질 정보를 확인한다.
5. 기상정보를 짧게 보여주고 지휘 판단을 돕는 통합 화면이라는 메시지로 마무리한다.

90초 설명에서는 모든 탭을 누르지 않는다. Semantic AI와 연동 대기 메뉴는 질문이 있을 때 연구·확장 범위로 설명한다.

## 전달받은 화면에서 확인되는 사실
- 상단은 Core 조회 정상, 지도 연결 8대, LIVE 0, STALE 0, OFFLINE 8로 표시돼 있다.
- 지도에 장비가 보이더라도 현재 실시간 수신 중이라는 설명은 할 수 없다.
- 영상 두 개는 연결 대기이며 통신 성공률도 측정값 없이 표시돼 있다.
- 날씨 영역은 기상모델이라는 라벨을 사용한다.
- 위 수치는 전달받은 화면 당시의 상태다. 행사 시점에는 다시 확인해야 한다.

## 예상 질문
**현장에서 인터넷이 끊겨도 전부 동작합니까?**  
현장망·게이트웨이·클라우드 연결 경로에 따라 다릅니다. 끊김과 마지막 수신 상태를 구분해 표시하며, 실제 오프라인 동작 범위는 연결된 장비와 실증 결과를 기준으로 설명드립니다.

**AI가 화재를 예측하거나 지시합니까?**  
이 화면에는 분석 레이어와 연구 기능이 포함돼 있습니다. 운영 검증을 마친 자동 판단 기능과는 구분하고 있으며, 현재는 현장 정보를 모아 지휘 판단을 지원하는 부분을 중심으로 설명드립니다.

**기상청의 관측값입니까?**  
현재 버전은 현장 좌표에 맞는 Open-Meteo 기상모델 정보를 사용합니다. 기상청 관측이나 차량 센서값과는 구분합니다.

**이 화면에서 드론을 조종합니까?**  
제공된 Uplink는 GCS가 받은 위치 정보를 상위 관제로 전달하는 모듈입니다. 비행 제어나 임무계획은 해당 모듈 범위에 포함되지 않습니다.

## 검증 결과와 한계
- 첨부 ZIP의 커밋 ID가 GitHub에서 조회한 회사 원본과 일치함을 확인했다.
- Front: 36개 테스트 파일, 192개 테스트 통과. TypeScript 및 Vite 빌드 통과.
- Core: 127개 테스트 통과. TypeScript 빌드 통과.
- Vendor: 6개 테스트 실행 묶음, 총 20개 테스트 통과. TypeScript 빌드 통과.
- 합계 339개 자동 테스트 통과. 현장 장비를 사용한 종단 간 실증 결과는 아니다.
- 사이트를 브라우저로 열었으나 이 검사 환경의 WebGL 초기화 제한으로 지도 화면을 확인하지 못했다. 사이트 전체 장애로 판정하지 않았다.
- 행사 PC에서 브라우저·지도, 실제 수신 장비, 영상 한 개, 외부정보 출처, 최종 수신 시각을 확인한 뒤 시연한다.
