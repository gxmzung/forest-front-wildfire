# 공공데이터·실제 장비 데이터 표시

## 최신 화면 정책

LED 형태·이동 문구·전광판 미리보기·전광판 탭을 제거한다. 데이터는 카드·표·텍스트로 표시한다. 이전 WEATHER_INTEGRATION.md의 전광판 UI 항목보다 이 문서가 우선한다. 실제 LED 장치 연동은 별도 장비 작업이다.

| 탭 | 표시 | 원본 |
|---|---|---|
| 현장 기상 | 기온·습도·풍향·풍속·1시간 강수량·예보·전국 특보 | 기상청 API |
| 산불위험 | 선택 시군구의 평균·최대·최소 위험지수, 분석시각 | 산림청 국립산림과학원 API |
| 대기질 | 인근 측정소 PM10·PM2.5, 측정소·거리·관측시각 | 에어코리아 API |
| 장비 위치 | 위경도·보고 속도·측위 방식·보고 정확도·기준점 대비 직선 이동량 | 기존 관제 장비 텔레메트리 |
| 통신망 | 보고 경로·지연·최근 SEQ 수신율·누락률 및 기존 통신 상세 | 기존 관제·장비 데이터 |

현장 기상에서 선택한 사건/기기/수동 좌표를 대기질 조회에도 사용한다. 기상 패널은 탭 이동 중 상태를 유지한다. 산불위험 행정구역은 직접 선택하며 좌표에서 임의 매칭하지 않는다. 위험지수를 임의의 경보 등급으로 변환하지 않는다. 분석시각이 6시간보다 오래되거나 형식이 불명확하면 안내한다. 이 기준은 화면 정책이다.

## 실제 수신 기준

- API 키·활용권한·자료가 없으면 미수신/설정 필요로 표시한다. 표본·모사값을 운영 화면에 만들지 않는다.
- 대기질 측정소 목록의 유효한 WGS84 좌표(dmX=위도, dmY=경도)로 직선거리상 가까운 측정소를 고른다. 인근 측정소는 현장 연기·유해가스 직접 측정값이 아니다.
- PM 점검 플래그·결측은 null, 실제 0은 0이다. 관측 후 3시간 초과·미래시각·갱신 실패는 지연 상태로 표시한다.
- 장비 위치는 측정/수신시각이 있는 텔레메트리를 사용한다. 등록 좌표나 브라우저 위치를 GNSS 측정값으로 대체하지 않는다. 속도·정확도는 동일 측정시각의 장비 보고값만 표시한다.
- 기준점은 사용자가 최신 장비 위치로 설정한다. 이동량은 누적거리가 아닌 기준점 대비 직선거리이며 GNSS 오차가 포함된다. 현재 사건 안에서 탭 이동 시 유지되며 새로고침·사건 변경 후 재설정한다.
- LTE·Wi-Fi 개별 성공/실패는 해당 경로의 실측 증거가 필요하다. 경로명·SEQ 통계만으로 두 링크의 성공 여부를 단정하지 않는다.

## 서버 준비

기존 VITE_WEATHER_API_BASE_URL을 공공데이터 조회에도 사용한다. 로컬은 127.0.0.1:18891이다. 기상청 KMA_WEATHER_SERVICE_KEY, 특보 KMA_WARNING_SERVICE_KEY(선택), 산림청 KFS_WILDFIRE_SERVICE_KEY, 에어코리아 AIRKOREA_SERVICE_KEY를 서버의 Git 제외 .env에서 관리한다.

신청 대상:
- 기상청 특보: https://www.data.go.kr/data/15000415/openapi.do
- 산림청 산불위험예보: https://www.data.go.kr/data/15084817/openapi.do
- 에어코리아 측정소정보: https://www.data.go.kr/data/15073877/openapi.do
- 에어코리아 대기오염정보: https://www.data.go.kr/data/15073861/openapi.do

프론트·서버 main을 모두 갱신하고 기존 프로세스를 종료한 후 재실행한다. 추가 npm 의존성은 없다. 확인 명령은 서버의 npm run check:environment -- 위도 경도이며 미설정/수신 실패도 각각 출력한다. 인증키는 출력하지 않는다.

## 검증 범위

파서·경로·실제 0/결측·측정소 선택·페이지 수집·오류 비밀정보 비노출·장비별 기준점 이동량·SSR 데이터 화면 계약을 자동시험한다. 실제 브라우저 E2E는 Chromium 실행 제한으로 미완료이며, 신규 산림청·에어코리아 실수신은 인증키/이용권한 설정 후 노트북에서 확인해야 한다. 실제 GNSS·LTE·Wi-Fi 장비 실증은 완료로 주장하지 않는다. 회사 저장소·운영 서버에는 배포하지 않는다.


## 실제 응답 형식 보완

2026-11-14 사용자 노트북에서 기상청·산림청 실수신 200을 확인했다. 산림청이 반환한 `2026-11-14 15` 형식을 KST로 인식해 최신 자료를 시각 형식 미확인으로 잘못 안내하지 않도록 보완한다. 에어코리아 실수신은 401로 실패했으며 측정소정보/대기오염정보 단계별 인증 오류를 구분한다. 신규 장비 실증은 미완료이다.
